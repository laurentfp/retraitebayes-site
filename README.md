# RetraiteBayes — site public

Simulateur probabiliste du solde du système de retraite français, calé sur le rapport annuel
du COR de juin 2026. Version statique, sans analyste IA.

**Site :** https://laurentfp.github.io/retraitebayes-site/

Ce dépôt est généré automatiquement (`npm run deploy:site`) : ne le modifiez pas à la main.
